# Stock & Revenue Dashboard Project

This project analyzes historical stock prices and quarterly revenue data of:

- Tesla (TSLA)
- GameStop (GME)

## Tools Used
- Python
- yfinance
- BeautifulSoup
- Pandas
- Matplotlib

## Key Insights
- Tesla showed strong growth in both stock price and revenue.
- GameStop stock price surged in 2021 without a similar revenue increase.

## Output
The dashboard compares stock price trends with company revenue.
